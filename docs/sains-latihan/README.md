**Setiap contoh hitung di folder ini wajib menjadi unit test** (lihat [08-pengujian.md](../08-pengujian.md)).

## Tingkat bukti

Tidak semua angka punya status yang sama. Setiap aturan diberi label:

| Label | Arti |
|---|---|
| **Standar** | Rumus/pedoman resmi dari lembaga (WHO, ACSM, EFSA, FAO) atau rumus baku yang dipakai luas |
| **Bukti ilmiah** | Berdasarkan meta-analisis atau position stand, tetapi masih ada rentang pendapat |
| **Aturan internal** | Keputusan aplikasi yang mengikuti prinsip ilmiah, tetapi angkanya ditetapkan sendiri. Wajib bisa diubah di `standards.ts` |

## Profil contoh

Pria, 24 tahun, 175 cm, 68,4 kg, aktivitas harian sedang, latihan 4×/minggu, tujuan menambah otot.
